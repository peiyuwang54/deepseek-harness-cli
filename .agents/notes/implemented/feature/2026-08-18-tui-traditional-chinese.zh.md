# Agent Note：终端繁体中文界面

状态：已实现

[English](2026-08-18-tui-traditional-chinese.md) | 中文

## 问题

终端界面提供简体中文，但没有繁体中文文案。用户只能持久化原有八种 locale 标识，中文选择项也没有区分可用的书写体系。

## 决策

共用的 `locale.preference` 设置接受 `zh-tw`，将其作为第九种界面语言。终端选择器把 `zh` 标为 `简体中文`，并加入 `繁體中文`；`/language` 也识别明确标识、两种中文写法与 `Traditional Chinese`。繁体中文拥有完整的终端框架与凭据管理文案，不在运行时转换简体中文。

浏览器仍只提供 `zh` 与 `en` 字典。它会校验并保留 `zh-tw` 这个共用终端偏好，但在所选语言没有浏览器字典时继续采用浏览器检测到的语言。

## 考虑过的替代方案

**在繁体中文标签下显示简体中文。** 拒绝，因为语言选择器必须准确描述界面实际显示的文字。

**运行时转换字符串。** 拒绝，因为书写体系转换无法选择符合地区习惯的术语，还会产生第二条隐式本地化路径。

## 验证

聚焦 TUI 测试覆盖别名解析、持久化、即时刷新界面、凭据文案与紧凑时长格式。locale Host 测试接受 `zh-tw`，并继续拒绝未知标识。无密钥终端快照固定选择器中的两种中文书写体系。

## 结果

DeepSeek Harness 对外说明支持九种界面语言。新增终端语言时必须同时补齐两套终端字典入口与共用偏好 schema；浏览器支持仍保持明确且独立。
