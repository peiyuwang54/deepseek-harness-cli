# DeepSeek Harness

English | [中文](README.zh.md)

DeepSeek Harness (`dsh`) is an open-source agent harness developed by [DeepSeek AI](https://deepseek.com).

It uses an architecture where **everything is a plugin**, and is powered by [Cordis](https://github.com/cordiverse/cordis), whose design is described in [_A Programming Paradigm for Spatiotemporal Composability_](https://github.com/cordiverse/paper).

## Developer preview

DeepSeek Harness is currently in _developer preview_ and is iterating rapidly. **THERE WILL BE COMPATIBILITY-BREAKING CHANGES.**

## Run

### Run from `npm`

Install `Node.js`, then open the interactive terminal coding agent:

```sh
npx @deepseek-ai/dsh
```

To start the Web UI instead:

```sh
npx @deepseek-ai/dsh web
```

See the [`dsh` CLI guide](apps/cli/README.md) for terminal commands and profiles, or the [Web UI guide](docs/user/guide/index.md).

### Run from source

To run the interactive terminal from a repository checkout:

```sh
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh
```

Use `pnpm dsh web` to start the Web UI.
